Network speeds are bits per second and decimal (SI): 100 Mbps is 100,000,000 bits a second, which is 12.5 MB/s at best. File sizes in operating systems are often binary (IEC): a GiB is 1,073,741,824 bytes, a GB is 1,000,000,000. Real transfers lose some to protocol overhead; this is the ideal.
